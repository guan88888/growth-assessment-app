# TabBar 图标说明

此目录需要放置以下图标文件：

## 需要的图标文件

1. `home.png` - 首页未选中图标
2. `home-active.png` - 首页选中图标
3. `quiz.png` - 测评未选中图标
4. `quiz-active.png` - 测评选中图标
5. `report.png` - 报告未选中图标
6. `report-active.png` - 报告选中图标
7. `me.png` - 我的未选中图标
8. `me-active.png` - 我的选中图标

## 图标要求

- 尺寸：建议 81x81px（小程序标准）
- 格式：PNG
- 风格：线性图标，简洁现代
- 颜色：
  - 未选中：灰色 (#999999)
  - 选中：蓝绿色 (#00C9A7)

## 临时方案

如果暂时没有图标，可以使用纯色占位图或使用文字图标。
